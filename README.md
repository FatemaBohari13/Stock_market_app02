📈 StockNest – Stock Market App

📌 Project Overview

StockNest is a responsive stock market dashboard designed to help users explore stocks, track market trends, manage a portfolio, maintain a watchlist, and view financial news.

This project is a frontend demo/prototype with sample stock data and simulated authentication, trading, and news features.

🚀 Key Features

- 🔐 Login & Sign Up screens
- 🔑 Forgot Password / OTP demo
- 📊 Market Overview
- 📈 Trending Stocks
- 🔍 Stock & Company Search
- 📋 Stock Details & Market Statistics
- 📉 Interactive chart period selection
- 💼 Portfolio Dashboard
- ⭐ Watchlist
- 📰 Financial News section
- 🗂️ News Categories
- 👤 User Profile
- ⚙️ Settings
- 🌙 Light & Dark Mode
- 📱 Responsive Mobile-Friendly Design
- 🧭 Bottom Navigation

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- CSS Flexbox
- Responsive Web Design
- SVG
